# Offline authenticated test network

`consensus.go` generates temporary RSA authority keys, a cross-certified authority
certificate and a signed six-relay microdescriptor consensus. Tests explicitly pin
only that generated authority. The normal consensus verifier and microdescriptor
hash checks run; the public-network authority list is never modified.

`tor-test-md.fixture` is a copy of the fixture in `pkg/parsers/microdesc`:
`test_md2_25` in Tor Project's `src/test/test_microdesc.c`, branch `maint-0.4.7`,
generated by Chutney. Source:
https://raw.githubusercontent.com/torproject/tor/maint-0.4.7/src/test/test_microdesc.c

Tests replace only the descriptor's Ed25519 identity with distinct temporary
keys, hash the resulting bytes, and include those digests in the signed consensus.
The fixture contains public keys only. It must never be used on the real network.
